Minesweeper by code, an 1890 punch card, and an AI world that drifts

One game makes you write code so a drone clears a minefield by itself. Another sends you to 1890 to run the US census on punch cards.

Two of this week's five games prove the same point: a science mechanic does not need spectacle, one rule can grow its own difficulty. One turns the code you write into your controls; one shrinks an 1890 census machine into a single line of weighted arithmetic. We also picked a Morse code rhythm game, a ten-year-old citizen science game about Alzheimer's, and an AI world model you cannot play yet but should know about.

ONHOLDNEWS No.01 · Nov 3, 2026 · 5 games where real science runs the mechanics

01 The Miner Was Replaced

Computer science · programming

What you do

You can't click a Minesweeper cell yourself. You write code that sends a drone to do it, in a language that looks like simplified Python. Get it wrong and the drone blows up. Other levels have you dig up ruins without breaking them, or sort mushrooms by color.

The tech behind it

Code is the interface: the drone does only what your program says, so every run is reproducible. Solving Minesweeper with code is a classic algorithms exercise.

Where to play

Platform: PC (Windows / macOS); included in the mobile base game
Price: Steam DLC, needs The Farmer Was Replaced (price to be checked)
Status: Out Nov 2, 2026

The base game launched on iOS / Android the same day, with the mining content included.

Our take

Best for people who code a little and want to watch their logic run. Code-the-robot games already exist (Bitburner, 7 Billion Humans); what is new here is the puzzles, such as writing a Minesweeper solver, not the framework.

Sources: Steam store page · Developer update, Nov 2 (SteamDB)

02 HOLLERITH

History of computing · data processing

What you do

You're a new operator on the 1890 census. Each card has 8 hole positions: the left half is weighted 4-3-2-1, the right half 1-2-3-4. Add up the weights of the punched holes on each side, compare, and sort the card left or right; ties and blank cards go back. Three jams and your shift is over. Later days add double holes, blanks and speed, up to 120 cards a shift.

The tech behind it

Based on Hollerith's tabulating machine for the 1890 US census, where metal pins passing through holes closed a circuit to count. The hole → value → sort chain matches the real machine; the weighting rule is the game's own abstraction to create mental math, not history.

Where to play

Platform: Browser, Windows / macOS
Price: To be checked
Status: 48-hour Ludum Dare 60 entry

Every visual is drawn by code with no image files; the sound is synthesized live.

Our take

Great if you like quick mental math or computing history. Jam comments mostly say the later days get too hard; the first two days show you the whole loop. One arithmetic rule carrying a whole game is the most elegant design this week.

Sources: Ludum Dare entry · Ludum Dare 60

03 The Telegraphist

Communication · Morse code · rhythm

What you do

You're a telegraph operator. Tap for a dot, hold for a dash, and keep to the beat of incoming messages. Messages get longer and you learn new letters along the way; miss a beat and the whole message can be lost.

The tech behind it

Morse code is a timing structure: the ratio of short to long signals defines each letter, which makes it a natural one-button rhythm input. The game uses the real dot-dash code.

Where to play

Platform: To be checked (no browser build stated)
Price: To be checked
Status: 48-hour Ludum Dare 60 entry, code made with AI help

Our take

Calm, almost meditative, and good if you want to pick up Morse along the way. There are already a few Morse rhythm games; this one wins on mood rather than novelty. Players mention the text is small on desktop.

Sources: Ludum Dare entry

04 Stall Catchers 10th-anniversary Catchathon

Neuroscience · citizen science

What you do

Watch a short clip of blood vessels in a mouse brain and decide whether the marked capillary is flowing or stalled. Score points and climb the team leaderboard. All of October was a global team event for the tenth anniversary.

The tech behind it

Cornell researchers found that in mice with Alzheimer's, white blood cells get stuck in brain capillaries and lower overall blood flow. Computers struggle to judge these stalls; human eyes do it well. Every answer is labeled data for the research, already used in several peer-reviewed papers.

Where to play

Platform: Web, mobile
Price: ✓ Free
Status: Game stays open; the anniversary event ended Oct 30

Our take

The lowest-friction way to turn play time into research time: one yes/no call. Ten years running with hundreds of thousands of players, it is the only pick this week with long-term retention behind it.

Sources: Human Computation Institute: 10th-anniversary Catchathon · Human Computation Institute blog

05 Genie 4

AI · world models

What you do

Generate a world from a line of text, then walk into it. Partway through you can type “make it rain”, add a person or change the camera, and the world changes on the spot. Ambient sound, music and character dialogue are generated live too.

The tech behind it

Google DeepMind's real-time interactive world model, with a “director” layer that breaks your goal into steps, checks the frame, and replans when interrupted. DeepMind lists its own limits: objects drift over long walks, and complex physics and readable text are still research problems.

Where to play

Platform: —
Price: —
Status: ✗ Research preview for trusted testers only; waitlist open

Our take

For now it is closer to a dream you can walk into than a game engine with stable rules. We include it because it shows another path: rules generated by a model instead of written by people. We'll come back when it opens.

Sources: Google DeepMind blog · TechCrunch
