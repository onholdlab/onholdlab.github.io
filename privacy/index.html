隱私權政策

最後更新:2026 年 10 月 26 日

這份說明適用於 onholdlab.github.io 底下的首頁、遊戲與工具。我們只收作品運作需要的資料,不賣資料,也不放廣告追蹤。

瀏覽統計(GoatCounter)

  • 用 GoatCounter 計算每一頁被看了幾次,記錄的是:網址、從哪個網站連過來、瀏覽器與裝置類型、螢幕大小、大概的國家。
  • 不使用 cookie,不建立個人檔案,也不會拿來辨認你是誰。

回饋表單

  • 你送出的留言、你選填的聯絡方式(email 或 IG)、送出時的網址和瀏覽器資訊。
  • 只用來看回饋和回覆你,存在 Supabase 資料庫,只有我們看得到。

遊戲排行榜

  • 你輸入的暱稱、分數、上傳時間,以及一組隨機產生的裝置代碼(只用來把同一台裝置的成績算成一筆)。
  • 排行榜是公開的:所有玩家都看得到暱稱和分數。請不要用真名或私人資訊當暱稱。

存在你瀏覽器裡的資料

  • 語言選擇、暱稱、最佳成績、遊戲設定、首頁的小遊戲紀錄、上面那組裝置代碼。
  • 這些只存在你自己的瀏覽器(localStorage),清除網站資料就會刪掉。

麥克風(拍手貓)

  • 拍手貓要你允許麥克風,用瀏覽器內建的語音辨識聽觸發詞。我們不錄音、不存聲音。
  • 語音辨識由瀏覽器提供,例如 Chrome 會交給 Google 處理,適用瀏覽器業者的政策。

其他服務

  • 網站放在 GitHub Pages;部分頁面從 Google Fonts、cdnjs 載入字型與程式;部分遊戲也上架在 itch.io。這些服務會依它們自己的政策處理連線資料(例如 IP 位址)。

想查詢或刪除你的資料

  • 用首頁的回饋表單,或私訊 Instagram @onholdlab,告訴我們要刪的留言或排行榜暱稱。
  • 這份政策有變動時,會更新這一頁和上面的日期。

Privacy Policy

Last updated: October 26, 2026

This applies to the homepage, games and tools under onholdlab.github.io. We only collect what the works need to run. We don't sell data and don't use ad trackers.

Visit statistics (GoatCounter)

  • We use GoatCounter to count page views. It records the page address, the site you came from, browser and device type, screen size, and approximate country.
  • It uses no cookies, builds no profiles, and isn't used to identify you.

Feedback form

  • Your message, the contact you choose to leave (email or IG), and the page address and browser info at the time you send it.
  • Used only to read feedback and reply to you. Stored in a Supabase database that only we can read.

Game leaderboards

  • The nickname you enter, your score, upload time, and a randomly generated device code (used only to count one entry per device).
  • Leaderboards are public: every player can see nicknames and scores. Please don't use your real name or private details as a nickname.

Data stored in your browser

  • Language choice, nickname, best scores, game settings, homepage mini-game progress, and the device code above.
  • These stay in your own browser (localStorage) and are removed when you clear site data.

Microphone (Clapping Cat)

  • Clapping Cat asks for the microphone and uses your browser's built-in speech recognition to hear the trigger words. We don't record or store audio.
  • Speech recognition is provided by the browser. Chrome, for example, sends it to Google, under the browser maker's policy.

Other services

  • The site is hosted on GitHub Pages. Some pages load fonts and scripts from Google Fonts and cdnjs, and some games are also on itch.io. These services handle connection data (such as IP addresses) under their own policies.

Questions or deletion

  • Use the feedback form on the homepage or DM @onholdlab on Instagram and tell us which message or leaderboard nickname to delete.
  • If this policy changes, we'll update this page and the date above.
